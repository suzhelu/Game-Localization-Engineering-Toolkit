# Release reference

Read [compilation evidence](../../../docs/compilation-adapters.md), [overlay format](../../../docs/overlay-packages.md), and [transaction recovery](../../../docs/deployment-transactions.md) for the requested phase.

Keep format validation, original byte-roundtrip comparison, translated structure preservation and runtime acceptance separate. Use explicit package file lists. Confirm deployment targets, baseline hashes, independent backups and authorization. After hard interruption inspect transaction evidence before recovery; unknown states require manual handling. Checksums are not signatures. Never publish game assets or third-party compilers as toolkit examples.
