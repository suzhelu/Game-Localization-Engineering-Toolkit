# Analysis reference

Read [BGI boundaries](../../../docs/bgi-adapter.md) when BGI syntax is established, [translation workflow](../../../docs/translation-workflow.md) when preparing tasks, and [CLI configuration](../../../docs/cli-workflow.md) before running commands.

Report: repository revision, authorized test-copy location (private report only), explicit input paths and hashes, observed syntax, supported/unsupported evidence, slot counts if extraction was actually run, unresolved issues, proposed next action and required human decisions. Do not infer menu order from filenames. `inspect` validates project configuration; it is not an engine detector. Glossaries constrain translation; compilation indexes map compiled scripts and must not be generated from glossary terms.
