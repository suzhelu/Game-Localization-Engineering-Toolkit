# Game Localization Engineering Toolkit

游戏汉化工程实践与可复用工具集

## 项目简介

本仓库用于整理游戏汉化工程中的技术方案、自动化流程、验证方法和可复用开发框架。

## 实践项目

Higurashi When They Cry Hou — Chapter 8: Matsuribayashi

- 目标文本槽：28,014
- 汉化批次：25
- Kakera 碎片脚本：53
- Steam 汉化覆盖包：173 个文件
- 翻译、编译及静态验证完成
- D 盘测试副本已完成通关测试
- Steam 覆盖包安装静态验证通过

## 核心技术

- Python 文本处理
- AI 辅助翻译
- 术语表管理
- 游戏脚本编译与验证
- SHA-256 文件完整性校验
- PowerShell 安全部署与回滚
- Steam 汉化覆盖包制作

## 仓库目标

将一次完整汉化项目中的技术经验，沉淀为可复用的工具、模板和工程规范。
