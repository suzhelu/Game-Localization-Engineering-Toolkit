# GitHub publication safety review

Review date: 2026-11-12

## Scope checked

Reviewed every file in this standalone toolkit directory, including the package, tests, synthetic examples, documentation, and project metadata. Source behaviors are documented in `code-migration.md`, including the BGI adapter, deployment behavior, overlay packaging, and translation workflow adapted from the actually used project scripts.

## Findings

- No original game scripts, game dialogue, completed translation text, compiled game files, game resources, fonts, executables, assemblies, saves, deployment manifests, or private backups are included. The BGI sample and parser tests contain only synthetic strings.
- No API credentials, private keys, or authentication values were found.
- No personal drive paths or machine-specific absolute paths are included in the package.
- Tests and example data are synthetic and use temporary directories.
- Runtime code uses only the Python standard library. A synthetic .NET reflection-binding regression test invokes the host PowerShell runtime when available and is skipped when it is unavailable; it does not load a vendor compiler or game assemblies. Package building uses the declared `setuptools` build backend; no runtime dependency is declared.
- `.gitignore` excludes caches, virtual environments, secrets, backups, game-resource directories, compiled game files, and save files.
- No third-party source or binary was copied into this package. The game-specific compiler and assemblies were excluded.
- The owner confirmed that the tools were primarily generated by Codex for this project; source review found no third-party restricted code or bundled tool requiring separate redistribution rights.
- The BGI adapter is an adaptation of the project's own actually used `lib/script.mjs` and parser tests, not copied from a third-party parser. It contains no compiler or game binary.
- The deployment module is a standard-library refactor of audited project-owned PowerShell behaviors. It includes no game-specific paths, candidate manifests, transaction logs, game content, or PowerShell source. Process-crash tests use only synthetic bytes under temporary directories.
- The deployment primitive stops for unknown target hashes, corrupt or missing backup proofs, root mismatch, malformed transaction state, or non-whitelisted changes. It does not claim recovery from power loss or arbitrary storage failures. It cannot prevent an uncooperative concurrent writer from racing between checks and replacement; callers must quiesce the target tree.
- The overlay packager requires a caller-provided explicit list with expected hashes; it does not scan and collect game resources or install the resulting ZIP. Archive and audit tests use only generated synthetic payload bytes in temporary directories. Corrupt archives, traversal, duplicate paths, missing files, hash mismatches, and partial-build cleanup are covered.
- The translation workflow contains no provider URL, API key, online client, real prompt transcript, project glossary values, game script, or translated dialogue. It provides only a provider protocol, local Mock Provider, generic prompt template, and synthetic fixtures. The local state format can contain caller-provided source and target text; users must keep such runtime state out of public commits when it contains protected content.
- The game project's bilingual term glossary and compiled-script dictionary were treated as distinct private inputs (term rules versus runtime file metadata); neither was copied. Tests and the example use synthetic terms and strings.
- The compilation module does not include the game's compiler assembly, runtime assemblies, original TXT/MG assets, or build reports containing private paths. It accepts only caller-supplied tools, uses argument arrays with `shell=False`, and has a local Mock Compiler. The .NET reflection test compiles a synthetic BCL-only class and does not load game code.
- The MGSC v1 validator is read-only and checks only the audited envelope fields. The compiled payload is opaque; there is no claim of full format support or runtime validity. Original roundtrip requires caller-supplied baseline data. The expected artifact index is synthetic build-output path/hash metadata, not a game compiler dictionary and not a glossary.
- The CLI composes the existing public APIs and adds no game-specific path, character, story data, glossary entry, compiler binary, or online service integration. Its example creates a synthetic project in a temporary directory; its tests use synthetic strings and temporary filesystem roots.
- CLI configuration rejects unknown adapters/providers and unsafe project-relative paths; script IDs are constrained path tokens, package paths are POSIX-relative and unique, deployment defaults off, and output collection is explicit. Human review and resolved-structure gates cannot be disabled. The CLI delegates deployment/recovery to the existing transaction module and does not offer a direct copy path.
- The local Mock Provider and Mock Compiler are the only built-in choices. An explicitly configured external compiler is caller-owned, runs via the existing argv-based adapter, and is not included. Online AI, runtime game testing, and semantic proof are not claimed.
- The CLI audit state is local and excluded by `.gitignore`; it may contain caller source/translation content and must not be published when private. Operation records are not signed or tamper-proof. The CLI's manually supplied observed-version value is an operator attestation, not an independent version probe.
- Process-termination coverage uses a worker that calls `os._exit` while compiling synthetic data in a temporary directory. A leftover marked build directory is retained for explicit operator cleanup; the framework does not claim automatic recovery from process termination, power loss, or filesystem faults.
- A scan of the proposed public files found no API keys, credential values, runtime personal paths, original game text, translated game text, or forbidden game file extensions. Migration provenance uses generic asset descriptions only; source-machine paths are excluded.
- The repository MIT License is scoped in the README to code and documentation the named holder is entitled to license; it does not grant rights to third-party game content.

## Publication conditions

The directory is clean for a human GitHub upload review. Review covered the listed repository contents and the owner's source-origin confirmation; it is not a legal opinion and cannot grant rights to third-party material.
