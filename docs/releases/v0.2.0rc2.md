# Game Localization Engineering Toolkit v0.2.0rc2

**Pre-release / 预发布版本**

## 版本定位

这是 v0.2.0 的第二个预发布候选。功能范围与 rc1 相同，本版修正了一个依赖检出目录位置的合成测试，并将安装示例固定到所选版本标签。它仍不是现成的游戏汉化补丁，也不承诺支持任意游戏。

## 相对 rc1 的修正

- 临时工作区边界测试现在使用受控临时根目录，不依赖仓库位于系统临时目录之外；增加了“根目录外拒绝”和“根目录内嵌套目录允许”的回归覆盖。
- Quick Start 与本发布说明均从 `v0.2.0rc2` 标签克隆，避免默认克隆仍指向较旧的 `main`。

## 安装与快速体验

请按 [Windows PowerShell AI Quick Start](../quickstart-for-ai-users.md) 安装。本发布候选的克隆步骤如下：

```powershell
git clone --branch v0.2.0rc2 --depth 1 https://github.com/suzhelu/Game-Localization-Engineering-Toolkit.git
Set-Location Game-Localization-Engineering-Toolkit
$pythonCommand = Get-Command python -ErrorAction SilentlyContinue
if ($pythonCommand) { $pythonExe = $pythonCommand.Source } else { $pythonExe = Read-Host 'Enter the full path to Python 3.10+ python.exe' }
& $pythonExe --version
& $pythonExe -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -e .
& .\.venv\Scripts\localize.exe --help
& .\.venv\Scripts\python.exe examples/agent-workflow/end_to_end.py
```

合成演示使用预写合成文本、Mock Compiler 和测试专用审核动作；它不是真实翻译或实际人工审核。

## 当前支持范围与限制

- 当前仅有有限 BGI 脚本文本槽适配；不支持任意游戏引擎自动识别、通用自动解包或回写。
- 不内置在线 AI 翻译服务。Mock 翻译不代表真实翻译，译文仍须人工审核。
- 不内置通用真实游戏编译器。真实编译器须由使用者合法持有并明确配置。
- MGSC v1 检查仅覆盖已确认的头部、表及长度边界，不解码负载。
- 静态检查和 Mock Compiler 不能证明真实游戏运行兼容。本次未验证真实游戏运行、真实编译器互操作、完整真实 BGI 语料、全新 Windows 设备或网络文件系统并发行为。
- 显式加载的第三方适配器会在当前 Python 进程内执行；审核者身份字段不构成身份认证。
- 不提供绕过 DRM、加密保护、反作弊或访问控制的能力。仓库不包含游戏资源、原始脚本、完整译文、第三方编译器或现成补丁。

## 验证结果

在 Python 3.10.11 环境中，本地候选主测试 242/242 通过，适配器模板测试 5/5 通过，10 个合成示例全部通过。`v0.2.0rc2` wheel 已在新的虚拟环境中安装，版本、CLI 和端到端合成流程验证通过。源码包与 wheel 的归档检查和 SHA-256 见 [v0.2.0rc2 Preparation Report](v0.2.0rc2-preparation-report.md)。这些结果仅证明列明的合成工作流和工具行为，不代表真实游戏运行验收。
