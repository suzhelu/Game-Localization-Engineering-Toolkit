# v0.2.0rc1 Post-release Verification Checklist

Run this checklist only after a separately authorized release. Do not mark items complete until evidence is recorded.

- [ ] GitHub tag `v0.2.0rc1` points to the approved full commit hash.
- [ ] GitHub Release exists and is marked **Pre-release**.
- [ ] Release title and notes match [`v0.2.0rc1.md`](v0.2.0rc1.md), including support limits.
- [ ] GitHub-generated source archive is downloadable and corresponds to the tag.
- [ ] If wheel and sdist are uploaded, each is downloadable and its SHA-256 matches the locally recorded build artifact.
- [ ] Do not mark a build artifact as uploaded or verified unless its name, size, and digest are recorded in the release evidence.
- [ ] Clone the public repository at the tagged commit into a clean directory.
- [ ] Create a new Python virtual environment and install using the documented steps.
- [ ] Confirm the installed package version and `localize --help` output.
- [ ] Confirm the Game Localization Skill and its references exist in the tagged source.
- [ ] Run all documented synthetic examples and record exit codes.
- [ ] Check README and release-note links from the public repository page.
- [ ] Review the tagged tree and release assets for unintended game resources, secrets, personal paths, caches, or unauthorized third-party tools.
- [ ] Record any failed or untested item as such; do not equate static checks with in-game acceptance.
