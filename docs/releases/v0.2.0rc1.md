# Game Localization Engineering Toolkit v0.2.0rc1

**Pre-release / 预发布版本**

## 版本定位

这是一个面向 AI Agent 协作的游戏本地化工程工具包。Agent 可依照项目规范、适配器接口、命令行工具和结构化交换文件，协助开展游戏文件分析、文本槽提取、翻译结果导入、结构质量检查、人工审核、编译验证和覆盖包制作。它不承诺支持任意游戏，也不是现成的游戏汉化补丁。

## 本次主要更新

- 增加 `AGENTS.md` 和可手动加载的 Game Localization Skill，提供 Agent 使用入口和安全工作约定。
- 增加显式适配器注册体系；当前包含有限范围的 BGI 文本槽适配器。
- 增加离线 JSONL 翻译交换、源与任务指纹检查、结构 QA 和 `pending_review` 审核门槛。
- TranslationStore 为遵循工具协议的本地进程提供 OS 锁和冲突检测。
- 增加带证据等级的游戏分析报告格式和 11 阶段任务协议。
- 增加使用合成输入的端到端工作流演示。
- 补充 Windows PowerShell 安装与快速开始、兼容性说明和 FAQ。

## 安装与快速体验

请按 [Windows PowerShell AI Quick Start](../quickstart-for-ai-users.md) 安装。简要步骤如下：

```powershell
git clone --branch v0.2.0rc1 --depth 1 https://github.com/suzhelu/Game-Localization-Engineering-Toolkit.git
Set-Location Game-Localization-Engineering-Toolkit
$pythonCommand = Get-Command python -ErrorAction SilentlyContinue
if ($pythonCommand) { $pythonExe = $pythonCommand.Source } else { $pythonExe = Read-Host 'Enter the full path to Python 3.10+ python.exe' }
& $pythonExe --version
& $pythonExe -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -e .
& .\.venv\Scripts\localize.exe --help
& .\.venv\Scripts\python.exe examples/agent-workflow/end_to_end.py
```

如果 `python` 不在 PATH 或触发 Microsoft Store 别名，脚本会提示输入已安装 Python 3.10+ 的 `python.exe` 完整路径。详细版本检查与替代方式见 Quick Start。合成工作流使用预写合成文本、Mock Compiler 和测试专用审核动作；它不是真实翻译或实际人工审核。

## 当前支持范围

- 通用路径安全、SHA-256、Manifest、显式文件清单和覆盖包审计。
- 保守的 BGI 脚本文本槽解析与受限安全回写；仅识别已支持的结构。
- 离线翻译交换、占位符/控制标记等结构校验、过期结果拦截和待人工审核状态。
- Mock 编译器流程、显式配置的外部编译器接口及有限静态产物检查。
- 在明示授权和事务保护下执行的部署/恢复接口；新项目默认禁用部署。
- Agent 可调用的 CLI、游戏分析报告和合成端到端演示。

## 已知限制

- 只有有限 BGI 文本槽适配；不支持任意游戏引擎自动识别或通用自动解包、回写。
- 不内置通用真实游戏编译器，用户必须合法持有并自行明确配置外部工具。
- 不内置在线 AI 翻译服务。Mock 翻译和 Mock Compiler 只验证工具流程，不代表真实翻译或真实游戏兼容。
- MGSC v1 检查仅覆盖已确认的头部、表和长度边界；不解码负载。
- 本次预发布准备未重新验证完整真实游戏脚本语料或任何游戏运行。静态验证不能替代游戏内验收。
- 所有游戏的字体覆盖、布局、菜单、存档和运行流程都不能由本工具保证。
- 显式加载的第三方适配器会在当前 Python 进程中执行，必须先审查并信任其代码。
- CLI 的审核者身份是记录字段，不是身份认证。
- 文件锁用于遵循协议的本地进程协调；网络文件系统行为未经验证，外部绕过工具的写入者不受锁保护。

## 测试与验证

本次候选已在新的 Python 3.10.11 虚拟环境中重新安装并验证：主测试 240 项、适配器模板测试 5 项、10 个合成示例均通过；wheel 与 sdist 已构建并检查归档内容。此证据仅覆盖合成工作流和工具行为，不代表真实游戏运行验收。逐项命令、资产 SHA-256 与未测试边界见 [v0.2.0rc1 Preparation Report](v0.2.0rc1-preparation-report.md)。游戏内验收仍需用户在确切游戏版本和环境中实际运行并记录。

## 反馈与贡献

请通过 GitHub Issues 报告问题。提供工具版本、操作系统、最小可复现步骤和删去敏感信息的日志；不要上传商业游戏脚本、提取文本、存档或资源包。新适配器应从合成样本开始，并遵循 [Adapter Development](../adapter-development.md)。

## 安全与版权

仅处理合法持有并获准处理的游戏文件，遵守游戏许可和第三方工具条款。此工具包不提供绕过 DRM、加密保护、反作弊或访问控制的能力。请勿向公开仓库传播原始商业游戏资源或未经授权的编译器。
